# Read Only Memory (ROM) Using Verilog HDL

## Description

This project implements a Read Only Memory (ROM) using Verilog HDL.

The ROM stores predefined data values and provides the stored data at the output based on the input address. Since ROM contains fixed information, the data can only be read and cannot be modified during normal operation.

This design demonstrates memory initialization, address selection, and data retrieval.

## Features

- ROM memory implementation
- Address-based data access
- Predefined memory contents
- Combinational read operation
- Synthesizable Verilog design
- Simulation using Icarus Verilog and GTKWave

## ROM Specifications

- Memory Size: 16 × 8 bits
- Address Width: 4 bits
- Data Width: 8 bits
